# Quality gates

Aplicar las puertas que correspondan. Bloquear publicación cuando falle una puerta crítica.

## Evidencia y actualidad

- Citar fuentes primarias para políticas, especificaciones, métricas y cambios de plataforma.
- Registrar fecha y alcance geográfico de información volátil.
- Separar observación, inferencia, recomendación e hipótesis.
- Marcar datos no verificados; no rellenarlos con estimaciones inventadas.
- Para YMYL, legal, salud o finanzas, exigir revisión experta y fuentes vigentes.

## Utilidad y originalidad

- Resolver una necesidad identificable de una audiencia real.
- Aportar experiencia, análisis, evidencia, ejemplos o herramientas más allá de resumir competidores.
- Eliminar secciones creadas solo para keywords o longitud.
- Mantener título, contenido y CTA alineados con la promesa de entrada.

## Claims y persuasión

- Mantener un mapa `claim -> evidencia -> condición/límite`.
- Verificar cifras, comparaciones, garantías, testimonios y endorsements.
- Mostrar divulgaciones claras donde exista relación comercial o resultado atípico.
- Evitar urgencia, escasez o autoridad falsas y cualquier impresión neta engañosa.
- Adaptar requisitos legales al país; no tratar esta skill como asesoría jurídica.

## Accesibilidad y claridad

- Usar headings y labels descriptivos.
- Escribir con el lenguaje más claro apropiado para la audiencia.
- Expandir abreviaturas y explicar términos inusuales cuando sea necesario.
- Mantener instrucciones y errores accionables.
- No depender solo de placeholder, color o posición para comunicar significado.
- Revisar consistencia entre texto visible y nombre accesible.

## SEO y plataforma

- Confirmar que la recomendación aplica a la versión, motor, mercado y feature actuales.
- No confundir sintaxis válida de schema con elegibilidad o ranking.
- No bloquear accidentalmente páginas, recursos o snippets necesarios.
- No implementar cambios masivos sin muestra, observación y rollback.

## Medición

- Definir baseline y métrica primaria antes del cambio.
- Incluir métricas guardrail: calidad, bajas, errores, devoluciones, soporte o rendimiento.
- Evitar optimizar métricas proxy desconectadas del negocio.
- No declarar ganador sin datos suficientes; documentar incertidumbre.

## Checklist de entrega

- [ ] Objetivo y audiencia explícitos
- [ ] Evidencia y fuentes identificadas
- [ ] Hechos, inferencias y recomendaciones separados
- [ ] Claims respaldados o marcados pendientes
- [ ] Riesgos técnicos, legales y de accesibilidad revisados
- [ ] Cambio priorizado y medible
- [ ] Aspectos no verificados declarados
