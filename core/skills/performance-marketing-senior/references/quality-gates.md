# Quality gates

## Negocio

- [ ] Objetivo de negocio y fuente de verdad definidos
- [ ] Margen, CAC/CPA máximo, payback y capacidad considerados
- [ ] Forecast con supuestos y escenarios, no promesa única
- [ ] Calidad posterior a la conversión incluida

## Medición

- [ ] Evento primario representa valor real
- [ ] Tags/APIs, deduplicación, value/currency e IDs verificados
- [ ] CRM/offline y retraso de conversión considerados
- [ ] Observado, modelado, atribuido e incremental separados
- [ ] Discrepancias entre plataforma, analytics y backend explicadas

## Privacidad y políticas

- [ ] Consentimiento y mercado objetivo identificados
- [ ] Datos minimizados y uso permitido
- [ ] ATT/CMP/Consent Mode aplicados cuando corresponde
- [ ] Categorías restringidas y políticas de anuncios revisadas
- [ ] Claims, testimonios, derechos y disclosures verificados

## Campaña

- [ ] Objetivo, conversión, audiencia/intención, oferta y landing alineados
- [ ] Bidding y presupuesto compatibles con señal y economía
- [ ] Exclusiones, brand safety, inventario y geografía revisados
- [ ] Recomendaciones de plataforma tratadas como hipótesis
- [ ] Cambio reversible y aprobación explícita antes de ejecutar

## Creativo y experimento

- [ ] Hipótesis estratégica explícita
- [ ] Prueba real para cada claim
- [ ] Métrica primaria, guardas, ventana y criterio de parada
- [ ] Variantes suficientemente distintas para aprender
- [ ] Accesibilidad y experiencia de destino revisadas

## Entrega

Bloquear una recomendación ejecutable si faltan economía mínima, fuente de verdad, aprobación de gasto o cumplimiento. Cuando falten datos no críticos, entregar diagnóstico y plan de instrumentación, no números inventados.
